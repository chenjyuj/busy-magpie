口径说明（本次实现刻意与卡片相反的一处）

主卡片回答「这个模型现在什么状态」，所以进行中时保留上一次完成请求的指标；明细浮窗回答「这一单请求发生了什么」，所以进行中的那一行只显示它自己的空缺（—）。两套规则各自有测试钉住：卡片侧在 tests/model-sessions.test.mjs，明细侧在 tests/requests.test.mjs 与 tests/ui/detail-window.cjs。
  完整版浮窗位置/尺寸都不持久化：位置每次由卡片位置推算（默认右侧 12px，放不下翻左并夹取到工作区内），尺寸默认 420×520、可原生拖边缩放但关掉即忘。
